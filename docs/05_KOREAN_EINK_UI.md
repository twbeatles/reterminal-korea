# 05. 한국형 800×480 전자잉크 UI 지시

## 2026-11-05 표시 상태 보강

- PM10/PM2.5는 실제 선택된 값의 관측시각을 각각 표시한다. 다른 시간의 값을
  공통 최신 시각으로 합치지 않으며 오래된 보완값은 마지막 정상값 배지로 구별한다.
- 최근 수집 실패와 값의 TTL은 별도다. 설정/인증 상태를 우선하고 최근 실패 시
  값이 있으면 마지막 정상값, 없으면 확인 필요를 표시한다. 다음 정상 수집 시 해제한다.
- 긴 배지는 PM 항목명과 경쟁하지 않도록 관측시각 아래에 둔다.
- Stale KIS 캐시보다 유효하고 기준시각도 더 최근인 FSC 값이 있으면 전일 종가
  라벨을 유지해 fallback한다. 현재가/종가/고시환율의 종류를 바꾸지 않는다.

## 정보구조
- 화면 1 `생활`: 현재 기온(크게), 날씨·3시간 예보, PM10/PM2.5, 실내 온습도.
- 화면 2 `시장`: USD/KRW 및 100JPY/KRW **고시환율**, 종목 2~4개(장중 현재가 or 전일 종가 레이블), 시장 상태.
- 화면 3 `기기`: Wi-Fi 연결, API 별 마지막 성공 시간, 배터리 상태, 관측/갱신시각, 페이지 조작 안내.
- 화면 상단 공통: 현재 KST 일시, 동네명, 연결상태. 하단: 데이터 출처와 시각, 오류/오래된 값, 페이지번호.

## 카드·아이콘 구성 (ADR 0008, 2026-11-02)
- 공통 헤더: 동네명 · `MM-DD(요) HH:MM` · Wi-Fi 아이콘(연결/미연결) · `시간 확인 필요` 배지.
  푸터: `●○○ 생활` 페이지 점 + DEMO 배지 + 데이터 출처.
- 카드 머리띠 = 24px 아이콘 + 18px 제목 + 1px 선. 핵심값은 64px 숫자로 쓰고, 64px 폰트에 없는 단위·등급은 아래 18px 줄에 쓴다.
- 생활: 좌측 `현재 날씨`(머리띠는 온도계 아이콘, 64px 날씨 아이콘, 기온, `흐림 · 예보 HH:MM`, 습도/강수량 아이콘 행) + `3시간 예보`
  (`22.0°C · 강수확률 60%` / `예보 MM-DD HH:MM · 흐림`, 기온은 한 번만 표시),
  우측 `대기질`(미세먼지/초미세먼지 큰 수치, 그 아래 `측정소 종로구 · 측정 HH:MM`) + `실내`.
- 시장: 좌측 `환율(고시)`($/¥ 64px 아이콘, `KRW / USD`, `KRW / 100JPY`, 큰 수치, 고시 기준일),
  우측 `관심종목`(최대 4행. 1줄 `종목명 … 값`, 2줄 `코드 · 현재가/전일 종가 · 기준`; 종목명은 오프라인 표에 없으면 코드로 대체) + 시장 상태.
- 기기: `기기 상태`(기기 아이콘 머리띠, Wi-Fi·배터리·시계 아이콘 행, FW) + `데이터 수신`(공급자별 마지막 성공).
  - 공급자 이름은 푸터 출처와 같은 한국어 이름(기상청 실황/예보, 에어코리아, 수출입은행, 금융위원회, 한국투자증권)을 쓰고,
    빈 행에는 이유(`센서 없음`/`설정 필요`/`키 확인 필요`/`수신 기록 없음`)를, 마지막 시도 실패 시 `최근 실패`를 붙인다.
  - 저전압(USB 아님) 또는 안전 모드로 기기 화면이 강제되면 경고 아이콘과 반전 배너로 이유를 표시한다.
  - 버튼 안내는 두 줄: `왼쪽 ◀ 이전 화면 · 가운데 ▶ 다음 화면` / `녹색 새로고침 · 녹색 2초 누르면 설정`. 앞에서 볼 때 왼쪽→오른쪽 순서가 KEY2(이전), KEY1(다음), KEY0(새로고침, 길게=설정)이다. ([ADR 0021](adr/0021-button-layout-nav-gray-action-green.md))
- 헤더 날짜·시각은 우측 열 시작(x=408)에 맞춘다.
- 시계 미확인 상태에서 녹색 KEY0(새로고침)를 누르면 NTP 동기화를 먼저 시도하고, 시계가 확인된 뒤에만 HTTPS 수신을 한다.
- 날씨 아이콘: PTY(비/비눈/눈/소나기/빗방울/눈날림)를 SKY(맑음/구름많음/흐림)보다 우선하고, 결측이면 `?`를 쓴다.
- 아이콘은 Material Symbols Outlined(Apache-2.0)를 `tools/icon_subset/make_icons.py`로 1bpp 변환해 쓴다. 아이콘은 라벨과 항상 함께 표시한다.
- 아이콘 24px 판별성과 64px 숫자 잔상은 **실기 확인 전(BLOCKED_HW)** 이다.

## 레이아웃 그리드 (실제 화소)
- 전체 800×480 / 좌우 안전 여백 20 / 상단 48 / 하단 36.
- 헤더: x=20..780, y=12..48. 컨텐츠 y=58..434, footer 440..468.
- 2열 패널: 좌측 x=20..392, 우측 x=408..780. 가독성 위해 레이블 14~18px, 핵심값 38~64px, 데이터시간 12~14px **실기 가독성 확인 후 조정**.
- 긴 숫자/종목명·지역명은 잘라내되 단위나 `기준일`을 제거하지 않는다. 말줄임과 원문은 설정 포털에 표시.
- 4-level gray: 텍스트 1bpp 중심, 차트 보조 선만 회색. 사진/그라데이션/애니메이션 사용하지 않음.

## 필수 UI 예시 (문구)

- 시장 상태([ADR 0033](adr/0033-market-state-labels.md)): 확인된 주말·공휴일·추가 휴장일만 `휴장`. 거래소 연간 일정 미검증 평일은 시간창에 따라 `정규장 시간` / `정규장 외`, 공휴일 표가 없으면 `일정 미확인`, 시계 미검증이면 `시간 미확인`. 거래소 일정 검증 시 `장시작 전` / `장중` / `장마감`을 구분한다. 달력의 `기호: 휴=휴장일 · 절=24절기`는 날짜 칸의 기호 범례이며 오늘의 상태가 아니다.
- `서울 종로구`, `기온`, `강수확률`, `초미세먼지`, `미세먼지`, `실내`, `환율(고시)`, `전일 종가`, `현재가`, `마지막 수신`, `관측`, `오래된 정보`, `확인 필요`, `Wi-Fi 미연결`, `DEMO`, `마지막 정상값`.
- `KRW / USD`, `KRW / 100JPY` 표기를 명확히. USD/KRW로 바꿀 경우 `1 USD = n KRW`와 중복하지 않음.
- **디자인에 가상 숫자**를 사용하더라도 Mock 프리뷰에는 굵게 `DEMO / 예시 수치` 넣는다.
- stale 예: `PM2.5 18 ㎍/㎥ · 관측 08:00 · 수신 08:10`; 네트워크 장애 시 `마지막 정상값 (2시간 전)` 배지 대신 일반 선/아이콘.

## 한글 글꼴 설계
- 라이선스 적합한 한글 서체(예: OFL 계열)를 검토하되 원본 폰트 파일은 이 지시서에 포함하지 않는다.
- 글꼴은 IBM Plex Sans KR(OFL): 14/18px Medium, 64px SemiBold를 2bpp(4계조)로 래스터한다(ADR 0014). 단위는 `㎍/㎥`(원본 글리프)를 쓴다.
- 영문/숫자 폰트 + 한글 필수 글리프 subset(사전 문자열 + 필요한 지역명 집합) 생성. 동적 종목명/주소는 glyph coverage 검증 및 fallback 적용.
- 폰트 제작 스크립트를 `tools/font_subset/`에 두고 원본 내려받는 URL, 라이선스·출처, 추가 문자를 만드는 방법을 문서화.
- 조사할 공식 예제: `E1001_ChineseTextDemo`, LVGL status panel의 `lv_conf.h` 및 `Seeed_GFX`.

## 갱신·잔상 정책
- API 데이터가 달라지지 않으면 화소 갱신하지 않는다.
- `refresh_region(rect)`은 패널·라이브러리의 영역 정렬과 지원 여부를 실기 검사한 뒤 적용. **Gray4 모드에서 partial 지원을 무조건 가정하지 말 것**.
- partial-refresh 허용 시 좁은 숫자 영역만 갱신, 5회 누적 뒤 full-refresh(`kMaxPartialsBeforeFull`, Good Display GDEY075T7 권장, ADR 0032). 모드마다 ghosting 기록.
- 빠른 화면 전환(설정 `fast_refresh`, 기본 꺼짐, [ADR 0034](adr/0034-fast-differential-refresh.md)): USB 전원에서 직전 프레임이 PSRAM에 있을 때만 흑백 전체 창 차분 갱신(OTP 빠른 부분 파형)을 쓰고, 5회 뒤 4계조 전체 갱신을 한다. 배터리 deep sleep 복귀, 포털 화면 뒤, 실패 뒤에는 Full. 실기(2026-11-24): 빠른 갱신 약 2초 vs 전체 4.7초, 반전 없이 표시(사용자 확인). 잔상·5회 주기는 검증 전(BLOCKED_HW).
- 동작온도: 기기 0–40°C(Seeed), 패널 0–50°C(Good Display). 범위 밖이면 UART 경고만 남기고 갱신은 계속한다. OTP 파형은 공식과 같이 온도값을 고정 주입하므로 저온 화질은 실기 확인 전(BLOCKED_HW)이다.
- 버튼 전환은 full refresh 허용(빠른 화면 전환이 켜져 있으면 위 규칙을 따름). 감지 못 한 버튼으로 수면이 풀릴 때 중복 화면 갱신하지 않음.
- 수집완료 vs 전자잉크 갱신완료를 분리. `last_rendered_at`는 패널 갱신 성공한 경우만 업데이트.
