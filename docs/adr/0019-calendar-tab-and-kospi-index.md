# ADR 0019 — 달력 탭과 코스피 지수

- 상태: 채택. 기기(COM5)에서 지수 수신과 부팅·갱신 로그 확인, **달력 화면은 기기에서 직접 보지 못함**(미리보기와 호스트 테스트만). 날짜 2026-11-11.
- 요청: 4번째 탭으로 달력, 시장 화면에 코스피 지수 추가 ([분석](../16_NEW_TAB_IDEAS.md)).

## 달력 탭

- 순서: 생활 → 시장 → **달력** → 기기(`Page::Calendar = 2`, 기기 탭은 3). 저장된 페이지 번호는 이 값이라, 이전 펌웨어가 NVS/RTC에 2(기기)를 저장했다면 달력으로 열린다(무해). 설정 코덱의 페이지 범위 검증을 0~3으로 넓혔다.
- 화면: 월 격자(7열), 오늘 반전, 공휴일 테두리, 주식 휴장 `휴`, 24절기 `절`, 오른쪽에 큰 날짜·요일·다음 공휴일(D-n)·다음 절기(D-n)·범례. 색이 없으므로 모양으로 구분한다.
- 데이터는 새 호출이 없다.
  - 공휴일·주식 휴장일: 기기가 이미 받아 두는 연도 표(`YearTable`).
  - 24절기: 한국천문연구원 특일 정보 API(`get24DivisionsInfo`)의 공개 응답을 2026-11-11에 받아 **상수표**(`SolarTerms.cpp`, 2026~2028, 연 24개)로 넣었다. 2029년 이후는 API가 비어 있어 "절기 정보 없음"으로 표시한다. 생성기 `tools/gen_solar_terms.py`와 픽스처 `test/fixtures/solar_terms_2026_2028.json`이 원본이고, pytest가 생성 결과와 일치하는지 검사한다.
  - 공휴일 이름: 고정 양력 휴일 8개만 이름을 붙이고(신정, 삼일절, 어린이날, 현충일, 광복절, 개천절, 한글날, 성탄절), 음력 기반·대체 공휴일은 이름을 추측하지 않고 "공휴일"로 표시한다. 공식 응답은 12/25를 "기독탄신일"로 주므로 표시 이름과 다르다.
- 시계가 확인되지 않으면(RTC·NTP 미확인) 날짜를 신뢰할 수 없어 "시간 확인 필요"만 보인다. 공휴일 표를 못 받은 상태면 "공휴일 정보 없음"으로 두고 휴일처럼 단정하지 않는다.
- 기념일·잡절·음력은 넣지 않았다(음력은 별도 활용신청 필요, 기념일은 항목이 많음).

## 코스피 지수

- 금융위원회 주가지수 API는 이 키로 `등록되지 않은 서비스키`(별도 신청 필요)라서 쓰지 않고, **이미 인증된 KIS의 업종지수 현재가 조회**(`inquire-index-price`, `tr_id FHPUP02100000`, `FID_INPUT_ISCD=0001`)를 썼다. 응답 필드(`bstp_nmix_prpr`, `bstp_nmix_prdy_ctrt`, `prdy_vrss_sign`)는 2026-11-11 PC 실호출로 확인했고, 기기에서도 `5357.01`, `+2.25%`가 수신됐다.
- 시장 화면 왼쪽 아래 한 줄(`코스피 5,371.68 +2.53%`, 조회 시각·REST)로 표시한다. 값은 소수 2자리를 ×100 정수로 보관한다.
- 호출: 종목 시세가 모두 성공한 뒤 같은 토큰으로 1회 추가한다(KIS 요청 상한 6 = 토큰 1 + 종목 4 + 지수 1). 지수 요청이 실패해도(예: 초당 제한 `EGW00201`) 종목 시세 성공 기록은 바뀌지 않고, 이전 값은 시간이 지나면 Stale로 표시된다.
- 코스닥(`1001`)은 PC 시험에서 초당 제한(`EGW00201`)에 걸려 값을 확인하지 못했고 구현하지 않았다. 필요하면 요청 간격을 정한 뒤 추가한다.
- (정정) 지수를 RTC/NVS에 보관하지 않던 제한은 [ADR 0023](0023-kospi-persistence-and-post-close-catchup.md)에서 해소했다(스냅샷 v3, 마감 후 1회 갱신).

## 검증

- 호스트: C++ 90개(+5: 지수 파싱·요청 격리, 달력 격자·경계·글리프), pytest 164개(+2), ruff 통과. 달력 경계: 윤년 2월, 연말→신정, 달력 미수신, 시계 미확인, 절기 표 밖의 해.
- 빌드: RAM 72,668 B(+1.8 KB), Flash 1,834,342 B(54.9%).
- 실기: 지수 수신과 KIS 요청 6회, 갱신 4.7초 유지. 달력 화면과 버튼으로 4개 탭 순환은 **직접 확인하지 못했다**(미리보기 `evidence/live-api-integration/font-preview/calendar-month.png`).
