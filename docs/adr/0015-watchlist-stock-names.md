# ADR 0015 — 관심종목 4개와 종목명 표시

- 상태: 채택, 실기 수신 확인 / 화면 육안 확인 대기. 날짜 2026-11-11.
- 요청: 주요 종목을 관심종목에 담고 종목코드 대신 종목명을 표시.
- 선택:
  - 기기 로컬 설정(`include/dev_credentials.h`, git 무시)의 관심종목을 `005930,000660,035420,005380`(삼성전자, SK하이닉스, NAVER, 현대차) 4개로 설정. 종목은 사용자 요청의 "주요 종목"을 해석해 고른 것이며 시가총액 순위를 근거로 하지 않았다. `kMaxWatchlist=4`가 화면(64px 행 4개)과 요청 예산(KIS 6/FSC 4) 한도다.
  - 종목명은 `src/domain/StockNames.*`의 오프라인 코드→이름 표(17종목, 정렬+이진탐색)에서 가져온다. 표에 없는 코드는 6자리 코드를 그대로 표시해 이름을 추측하지 않는다.
  - 금융위원회 응답의 `itmsNm`은 쓰지 않았다. 호출이 평일 13:00 KST 이후라서 오전에는 이름이 비고, 종목별 이름 필드 저장에 RAM이 더 든다.
  - 행 구성: 1줄 `종목명 … 값`, 2줄 `코드 · 구분(현재가/전일 종가) · 기준`. 이름이 없으면 1줄에 코드, 2줄에 구분·기준.
- 검증:
  - native 80/0. 신규 `test_stock_names_table_and_glyphs`가 표 정렬, 모든 이름의 □(누락 글리프) 0개, 이름 폭 190px 이하, 뷰모델의 이름/코드 폴백을 고정한다.
  - 실기(COM5): `watch=4`, KIS 현재가 4종목 VALID(HTTP 200, 첫 수신 requests=5 = 토큰 1 + 종목 4, 이후 requests=4). 부팅 직후 tokenP 분당 1회 제한으로 첫 시도는 RATE_LIMITED(403)였고, 기기가 백오프 뒤 재시도해 성공했다. 반복 재부팅은 이 제한에 다시 걸릴 수 있다.
  - 미검증: 실제 패널에서의 4행 레이아웃 육안, 금융위원회 4종목 오후 13시 이후 호출.
- 한계/대안: 표에 없는 종목은 코드로 보인다. 포털에서 종목을 입력하면 이름이 비는 문제를 없애려면 이름 표 확대 또는 FSC 이름 저장이 필요하다(별도 ADR).
- 범위 밖: 컨센서스(애널리스트 목표주가·추정치)는 KIS/FSC 공식 API 범위에 없어 이번 변경에 포함하지 않았다.
