# ADR 0025 — 생활↔시장 자동 순환, 시장 화면의 금융위원회 종가 표시

- 상태: 채택. 호스트 테스트와 펌웨어 빌드만 검증했다. **순환·포털은 기기에 올려 보지 않았다.** 날짜 2026-11-12.
- 요청: (1) 생활·시장 탭을 5분마다 자동 순환, (2) 시장 탭은 9~16시에만 순환하도록 설정, (3) 금융위원회 API 내용이 안 보이는 문제 확인.

## 1. 자동 순환

- 설정 `DeviceConfig`(스키마 v3, 포털 "기기 설정"): `auto_rotate`(기본 켜짐), `rotate_minutes`(1~60, 기본 5), `market_hours_only`(기본 켜짐), `market_from_hour`(기본 9)·`market_to_hour`(기본 16, 시각은 KST, `from <= 시 < to`).
- 정책은 순수 함수 `app::DecideRotation`([PageRotation.cpp](../../src/app/PageRotation.cpp)), 실행은 `main.cpp loop()`.
  - **USB 전원일 때만** 동작한다. 배터리는 갱신 때만 깨어나므로 5분마다 패널을 다시 그리면 전력을 잃는다.
  - 현재 화면이 생활/시장일 때만 순환한다. 달력·기기 탭은 사용자가 고른 화면이라 건드리지 않는다.
  - 버튼을 누르면 타이머가 다시 시작한다(부팅, 버튼, 순환 때마다 `last_page_change_ms` 갱신).
  - 장 시간 밖(또는 시각 미확인)이면 생활에 머문다. 시장 화면에 있었다면 간격이 지났을 때 생활로 돌아온다.
  - 전환은 `RunCycle(Button, None)` + `redraw_requested`로 그린다(패널 갱신 정책은 기존 버튼 전환과 같다).
- 한계: 평일/공휴일은 구분하지 않는다(시각만 본다). 필요하면 달력 계층(`IsKrxOpen`)을 쓰도록 확장할 수 있다.
- 되돌리는 방법: 포털에서 "자동 순환" 끄기.

## 2. 금융위원회(FSC) "안 불러와진다" 조사

- 키·API: 로컬 키로 PC에서 같은 URL 모양으로 호출해 HTTP 200, `resultCode 00`, 삼성전자 최신 기준일 2026-11-10 종가 198,900원을 확인했다(키와 URL은 기록하지 않음).
- 기기: 부팅 직후 UART 스냅샷에 4종목 모두 `전일종가 … VALID`(005930 198,900, 000660 1,212,000, 035420 193,000, 005380 275,000)로 들어와 있었다. **수신은 정상이다.**
- 원인: 시장 화면이 KIS 현재가가 있으면 그것만 보이고 금융위원회 종가는 현재가가 없을 때만 보였다. 그래서 금융위원회 값이 화면에 나오지 않았다.
- 변경: 현재가 행의 보조 줄을 `HH:MM · 종가 198,900 (11-10)` 형식으로 바꿔 종가와 **기준일**을 같이 표시한다. 종가가 없으면 기존 `조회 · REST`. 현재가 라벨은 그대로 두어 실시간과 종가를 혼동하지 않게 한다.
- 별개의 확인 사항: 종가는 영업일 13시 이후에만 새 기준일이 올라온다. 오전에는 직전 영업일이 아니라 그 전 영업일 값이 보일 수 있다(예: 11-12 오전에 11-10). 이것은 API 게시 시각 때문이며 오류가 아니다.
- 남은 위험(수정하지 않음): 인증 오류(HTTP 401/403 등)가 한 번이라도 나면 `auth_blocked`가 설정 변경 전까지 풀리지 않는다. 일시적 게이트웨이 오류도 영구 차단이 될 수 있다. 이번 조사에서는 발생 증거가 없어 정책을 바꾸지 않았다. 바꾸려면 별도 ADR이 필요하다.
