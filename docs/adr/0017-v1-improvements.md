# ADR 0017 — v1 개선 묶음 (Wi-Fi 감시, FSC 최초 조회, 등락률, 이름 표 확대, 주기 배율)

- 상태: 채택(호스트 테스트·빌드 확인). 실기 확인은 아래 "미검증". 날짜 2026-11-11.
- 배경: [펌웨어 점검](../15_FIRMWARE_REVIEW_2026-11-11.md)의 후보 중 코드로 해결 가능한 것을 반영했다. 실기·조사가 필요한 항목은 남겼다.

## 영향과 한계

- 포털(설정 화면)에서 주기를 바꾸는 기능은 만들지 않았다. NVS 스키마 버전과 마이그레이션 변경이 필요해서이며, 현재는 빌드 설정만 지원한다. 필요하면 별도 ADR로 진행한다.
- 이름 표에 없는 종목은 여전히 코드로 표시된다.
- 재연결 정책의 효과(끊김 빈도, 복구 시간)는 며칠 운용 로그가 있어야 판단할 수 있다.

## 미검증

- 위 변경은 이 문서를 쓰는 시점에 실기에 올리지 않았다. 호스트 테스트 통과와 컴파일 성공을 실기 정상으로 올리지 않는다.
- 금융위 최초 조회가 기기에서 응답을 받는지, KIS 등락률이 실제 화면에 나오는지, Wi-Fi 재연결 로그는 실기 확인 대기.
