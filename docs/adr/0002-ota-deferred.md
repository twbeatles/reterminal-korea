# ADR 0002 — OTA는 USB 복구 완성 후, 기본 OFF로 연기

- 상태: 채택
- 날짜: 2026-11-02 (KST)
- 질문: 첫 릴리스에 OTA를 포함하는가.
- 선택: 포함하지 않는다. USB 복구 경로(`docs/RECOVERY.md`) 완성·실기 검증이
  먼저다. 이후 선택적 로컬 OTA만 설계한다: (a) 기기 AP/로컬망 업로드, 또는
  (b) 사용자 확인 후 공개 릴리스 자산 다운로드. 상시 백엔드는 불필요.
- 요구사항 (도입 시): 이미지 해시 + 릴리스 서명/검증 키, 롤백 슬롯,
  실패 시 이전 부팅 슬롯 보존. ESP32 secure boot/flash encryption 영구 fuse는
  사용자 명시 승인 없이 금지.
- 근거: 08 릴리스 게이트 (복구 없는 OTA는 벽돌 위험).
- 되돌리는 방법: USB 복구 실기 검증 완료 후 OTA 설계를 P6 후속 티켓으로 개시.
