# ADR 0033 — 미확인 거래소 일정과 휴장 표시 구분

- 상태 / 날짜: 채택 / 2026-11-17 KST
- 질문: 정상 시세를 수신하는 평일에도 시장 탭이 `휴장 가능`을 표시하고, 달력의 고정 범례가 오늘의 휴장 상태로 읽힌다.
- 원인: 공휴일 표 수신 여부와 별개로 `market_verified=false`인 모든 평일에 `휴장 가능`을 반환한다. 특일 API는 거래소 연간 예외 일정의 검증 근거가 아니므로 이 플래그를 임의로 켤 수 없다.
- 선택: 시각 미검증은 `시간 미확인`, 해당 연도 공휴일 표 부재는 `일정 미확인`. 주말·공휴일·명시된 거래소 휴장일은 `휴장`. 공휴일 표만 있는 평일에는 기존 KRX 시간창 기준 `정규장 시간` / `정규장 외`를 표시한다. 거래소 일정 검증 시 `장시작 전` / `장중` / `장마감`을 구분한다. 달력은 `기호: 휴=휴장일 · 절=24절기`로 범례임을 드러낸다.
- 영향: 시장 상태 문자열 버퍼를 32바이트로 늘려 한글 잘림을 막는다. 시세 파싱, 캐시, 조회 주기, 거래일 판정, 달력 날짜별 마크는 변경하지 않는다.
- 다른 선택지: 평일을 모두 실제 `장중`으로 단정하거나 시세 응답 성공으로 개장을 확정하는 방법은 채택하지 않는다. 정상 HTTP/API 성공이나 캐시된 현재가는 실제 개장의 증거가 아니다. 새로운 휴장 조회 API 추가는 별도 작업이다.
- 근거: `Calendar::MarketStateText`, `HolidayService::ParseHolidayYear`, `Renderer::RenderCalendar` 실제 소스. 기존 시간창을 재사용하며 새 금융 일정·API 계약을 가정하지 않는다.
- 검증 증거: `evidence/market-labels-2026-11-17/summary.md`. 평일·주말·공휴일·추가 휴장·미확인 시각/연도·09:00/15:30 경계·한글 글리프·UTF-8 버퍼·2026-11-17 달력 마크를 Host에서 확인한다.
- 되돌리는 방법: 이 ADR의 소스·테스트·프리뷰 변경을 함께 되돌린다. 저장 데이터 형식 변경은 없다.
